Python Beginner Assignment

Project Description

This project is created to learn Python programming from the basics and develop simple working programs.

Objective

To understand Python fundamentals and independently create beginner-level Python programs.

Software Requirements

- Python 3
- Visual Studio Code
- Git

Python Topics Covered

- Python Syntax and Indentation
- Comments
- Variables
- Data Types
- Type Conversion
- Operators
- Input and Output
- Conditional Statements
- For and While Loops
- Functions
- Lists
- Tuples
- Sets
- Dictionaries

Exercises Completed

1. Employee Details
2. Area of a Rectangle
3. Even or Odd Number
4. Exam Grade Calculator
5. Multiplication Table
6. Sum of Numbers Using While Loop
7. Square of a Number Using Function
8. Unique Numbers Using Set

How to Run the Programs

1. Install Python 3.
2. Open the project folder in Visual Studio Code.
3. Open the required Python file.
4. Open the VS Code terminal.
5. Run the program using:

"python "Exercise 8.py""

Replace the filename with the program you want to execute.

Program Explanations

1. Exam Grade Calculator

This program accepts an exam score and uses if, elif and else statements to display the appropriate grade.

2. Unique Numbers Using Set

This program uses a Python set to remove duplicate numbers and counts the total unique values using len().

Conclusion

This project helped me understand Python basics and develop simple programs using variables, conditions, loops, functions and collections.
